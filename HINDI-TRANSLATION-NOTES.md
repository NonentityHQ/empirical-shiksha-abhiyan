# Hindi translation coverage

This project uses a curated offline translation dictionary in `src/locales/hi.ts`; it does not call a translation API or make external network requests for Hindi. The current static page copy is covered across Home, About, Initiatives, Initiative Detail, Impact, Gallery, Success Stories, Our Stars, Star Detail, Contact, Reports, shared navigation, forms, and footer.

The About page has dedicated entries for its full story chapters, founder profiles, pillar descriptions, key milestones, FAQs, and calls to action. Unknown or newly authored text is intentionally left in English until a meaningful Hindi version is reviewed and added. This is preferable to presenting an incorrect literal translation.

After changing page content, add matching source phrases and Hindi values to `src/locales/hi.ts`. Use natural, context-appropriate Hindi and preserve names, dates, counts, programme labels, and legal meaning.
